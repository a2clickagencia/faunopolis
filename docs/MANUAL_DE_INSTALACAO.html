Não há instalador. Faunópolis é um jogo HTML5: não instala programas, não altera o registro do Windows e não precisa de permissões de administrador. “Instalar” é apenas guardar a pasta.

2. Instalação rápida (Windows)

  1. Copie a pasta Faunopolis para onde preferir (ex.: Documentos\Jogos\Faunopolis). Se recebeu um arquivo .zip, clique com o botão direito → Extrair tudo… antes de jogar.
  2. Dê dois cliques em JOGAR.bat. O jogo abre no navegador padrão.
  3. Alternativa: dê dois cliques em index.html ou arraste-o para uma janela do Chrome/Edge.
  4. Opcional: para criar um atalho na Área de Trabalho, clique com o botão direito em JOGAR.bat → Mostrar mais opções → Enviar para → Área de trabalho (criar atalho).
Tela cheia: pressione F11 no navegador. Para sair, F11 de novo.
Aviso do Windows SmartScreen. Arquivos .bat baixados da internet podem exibir “O Windows protegeu o computador”. O JOGAR.bat apenas abre o index.html (você pode conferir o conteúdo abrindo-o no Bloco de Notas). Se preferir, abra o index.html diretamente.

3. macOS e Linux

  • Abra index.html com dois cliques (ou clique com o botão direito → Abrir com → Chrome/Firefox/Safari).
  • No Linux, também é possível: xdg-open index.html.
  • No macOS: open index.html no Terminal, a partir da pasta do jogo.

4. Executar com servidor local (opcional)

O jogo funciona abrindo o arquivo diretamente. Um servidor local é útil para desenvolvimento, para testar em outros dispositivos da rede ou se o navegador tiver políticas que restrinjam arquivos locais.

Windows (com Python instalado)

Dê dois cliques em SERVIDOR_LOCAL.bat. Ele inicia python -m http.server 8080 na pasta do jogo e abre http://localhost:8080. Feche a janela preta para parar o servidor.

Manual (qualquer sistema)

# Python 3
cd Faunopolis
python -m http.server 8080

# ou Node.js
npx --yes serve -l 8080 .

Depois acesse http://localhost:8080.

Atenção aos salvamentos: o navegador guarda salvamentos por endereço. Jogos salvos em file:///…/index.html não aparecem em http://localhost:8080 e vice-versa. Use Exportar para arquivo e Importar para levar o progresso de um para o outro.

6. Salvamentos e backup

  • Salvamentos ficam no armazenamento local do navegador (localStorage): automático (a cada 3 dias de jogo e ao sair) + 3 espaços manuais.
  • Backup: Menu ☰ → Salvar → Exportar para arquivo. Gera NomeDoZoo_diaN.faunopolis na pasta de downloads.
  • Restaurar / trocar de computador: Menu principal → Carregar jogo → Importar arquivo .faunopolis.
  • Limpar os dados de navegação do site (cookies e dados de sites) apaga os salvamentos. Navegação anônima não mantém salvamentos.

7. Atualizar e desinstalar

Atualizar: exporte seus salvamentos, substitua a pasta pela versão nova e importe se necessário (normalmente os salvamentos continuam no navegador, desde que você abra o jogo pelo mesmo caminho).

Desinstalar: apague a pasta Faunopolis. Para remover também os salvamentos, limpe os dados do site no navegador.

8. Publicar na internet

Por ser um site estático, o jogo pode ser hospedado em qualquer serviço de páginas estáticas, enviando o conteúdo da pasta (com index.html na raiz):

  • itch.io: compacte a pasta em .zip, crie um projeto do tipo HTML, envie o arquivo e marque “This file will be played in the browser”. Tamanho de janela sugerido: 1280×720 com botão de tela cheia.
  • GitHub Pages, Netlify, Vercel, Cloudflare Pages: publique a pasta como site estático, sem comando de build.
  • Para empacotar como aplicativo de desktop, ferramentas como Electron, Tauri ou NW.js podem carregar o index.html sem alterações no código.
